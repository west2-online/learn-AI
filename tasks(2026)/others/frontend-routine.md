# Frontend Routine

## 学习目的

Python 前端的生态远不如前端主流框架。

但它仍然可以用于快速验证原型，尤其是 AI 相关的演示原型。

在 Agent 时代，前端的价值不止于写页面。Agent 的交互层——对话式 UI、Generative UI、computer-use / GUI Agent——本质是前端与客户端问题：流式渲染、人机协作流程设计（Human-in-the-loop）、对浏览器 / 桌面 / 手机环境的操作与感知。如果选择应用方向并希望做出差异化的作品集，这是一个值得关注的方向，可以结合 [Application 3](../application/application3.md) 的「好玩的东西 Plus」一起考虑。

## 学习内容

[前端从入门到如土](https://github.com/west2-online/learn-frontend)

Gradio / Streamlit

- Agent 交互层基础：流式输出（SSE / WebSocket）、对话式 UI、Generative UI
- computer-use / GUI Agent（可选）

## 作业

你可以使用 Python 前端框架完成前端组相关作业来检验学习效果。这些作业不强制提交，但欢迎提交展示并参与答辩。

更推荐你直接尝试前端组或美术组考核。在当前 AI 时代，虽然生成式工具降低了入门门槛，但高质量的审美与交互设计仍然高度依赖人的判断。
