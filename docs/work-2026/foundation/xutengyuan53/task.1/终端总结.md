# 终端使用与 IDE 运行按钮解析

## 1. 终端基本使用
在完成 Task 1 的过程中，我频繁使用了终端。
*   **遇到的问题**：一开始直接运行 `python check_my_code.py` 报错找不到文件，因为我当时在根目录，没有进入到 `Nabia_Snack_Incident` 文件夹中。后来通过 `cd` 命令切换到正确的目录下，测试脚本才成功跑通。
*   **解决思路**：遇到 `No such file or directory`，第一反应就是先检查终端当前所在的路径（`pwd`），看自己是不是“走错房间”了。

## 2. VS Code 右上角的三角形运行按钮
*   **这个按钮是干什么的**：在 VS Code 打开 Python 文件时，右上角会有一个三角形（Play）按钮。点击它，VS Code 会自动打开底部的终端，并帮你输入 `python 文件名.py` 这个命令。
*   **理解**：这是一个快捷键，本质和我在终端里手动敲命令是一模一样的。对于新手来说，它可以一键运行程序；但对于需要带参数、或者有复杂目录结构的工程来说，直接敲终端命令往往更自由、不容易出错。
